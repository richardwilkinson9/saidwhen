What AI companies said, and when they said it.

usage policies · model cards · terms · deprecation notices

These documents are edited constantly and quietly. A clause is softened, a capability claim disappears, a permitted use becomes a prohibited one. The previous version simply stops existing — no changelog, no notice.

This archive fetches them daily and keeps every version in git. The snapshot is not the point; the history is.

git clone https://github.com/richardwilkinson9/saidwhen
git log -p archive/anthropic/usage-policy.txt

That command prints every change to Anthropic's usage policy, in order, with the date each was observed.

OpenAI's policy pages return 403 to non-browser clients. That gap is recorded rather than worked around by pretending to be a browser — an archive whose own conduct is questionable is worth less than no archive.

What it will not do

Nothing is interpreted. No summaries, no "what this means", no view on whether a change is good or bad. The diff is the product.

A failed fetch never overwrites a good snapshot. Replacing a real policy with a block page would be the one error this cannot afford.

Contributing

Adding a source is a pull request editing sources.json. Missing something is a gap; claiming coverage that isn't real would be worse.

Archived documents remain the copyright of their publishers, reproduced as a factual record of what was published and when, with the source URL on every file. The code is MIT. If this project disappears, the git history is the whole thing and it is yours to keep.
